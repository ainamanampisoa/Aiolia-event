# MVola Sandbox - Informations de Test

## Numéros de Test

Les numéros suivants sont utilisés pour les tests dans l'environnement sandbox MVola :

| Numéro | Description |
|--------|-------------|
| `0343500003` | Numéro de test client 1 |
| `0343500004` | Numéro de test client 2 |

## Codes PIN de Test

**⚠️ IMPORTANT :** Les codes PIN exacts doivent être obtenus depuis :
1. La documentation officielle de l'API MVola MerchantPay
2. Les emails d'accès au sandbox MVola
3. Le support technique MVola

### Codes PIN couramment utilisés dans les sandbox :

| Numéro | Code PIN possible | Notes |
|--------|-------------------|-------|
| `0343500003` | `0000` ou `1234` ou `0003` | À vérifier dans la documentation MVola |
| `0343500004` | `0000` ou `1234` ou `0004` | À vérifier dans la documentation MVola |

**Note :** Les codes PIN peuvent être :
- `0000` (code par défaut souvent utilisé)
- `1234` (code commun dans les sandbox)
- Les 4 derniers chiffres du numéro (`0003` pour 0343500003, `0004` pour 0343500004)

## Configuration Sandbox

- **URL API Sandbox :** `https://devapi.mvola.mg`
- **URL API Production :** `https://api.mvola.mg`

## Comment tester

1. Utilisez uniquement les numéros de test : `0343500003` ou `0343500004`
2. Entrez le code PIN correspondant (à vérifier dans la documentation MVola)
3. Validez la transaction pour finaliser le test
