### 1. **Schema.sql Mis à Jour**

La table `ticket_chance_entries` a été modifiée avec les nouvelles colonnes :

```sql
CREATE TABLE IF NOT EXISTS ticket_chance_entries (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    user_id BIGINT NOT NULL REFERENCES users(id),
    event_id BIGINT REFERENCES events(id) ON DELETE SET NULL,
    prize_type promotion_type_enum NOT NULL,
    prize_value NUMERIC(12,2) NOT NULL DEFAULT 0,
    prize_code VARCHAR(50),              -- ✨ NOUVEAU
    promo_code VARCHAR(50),              -- ✨ NOUVEAU
    play_type VARCHAR(20) NOT NULL DEFAULT 'free', -- ✨ NOUVEAU
    order_id BIGINT REFERENCES orders(id) ON DELETE SET NULL, -- ✨ NOUVEAU
    metadata JSONB DEFAULT '{}'::jsonb,  -- ✨ NOUVEAU
    status ticket_chance_status_enum NOT NULL DEFAULT 'won',
    created_at TIMESTAMPTZ NOT NULL DEFAULT now(),
    claimed_at TIMESTAMPTZ
);
```

**Index ajoutés** pour les performances :
```sql
CREATE INDEX IF NOT EXISTS idx_ticket_chance_entries_user_date ON ticket_chance_entries(user_id, created_at DESC);
CREATE INDEX IF NOT EXISTS idx_ticket_chance_entries_play_type ON ticket_chance_entries(user_id, play_type);
CREATE INDEX IF NOT EXISTS idx_ticket_chance_entries_order ON ticket_chance_entries(order_id) WHERE order_id IS NOT NULL;
CREATE INDEX IF NOT EXISTS idx_ticket_chance_entries_status ON ticket_chance_entries(user_id, status);
```

## 🔄 Procédure de Réimportation

### ⚠️ IMPORTANT : Sauvegarde

Avant de réimporter, **sauvegardez vos données importantes** :

```bash
# Sauvegarder uniquement les données utilisateurs et événements
pg_dump -U aiolia_user -h localhost aiolia_event \
  --data-only \
  --table=aiolia.users \
  --table=aiolia.events \
  --table=aiolia.orders \
  --table=aiolia.tickets \
  > backup_data_$(date +%Y%m%d_%H%M%S).sql
```

### Option 1 : Réimportation Complète (Base Vide)

**Si vous voulez repartir de zéro** :

```bash

sudo -u postgres psql

# 2. Dans psql, supprimer et recréer
DROP DATABASE IF EXISTS aiolia_event;
DROP ROLE IF EXISTS aiolia_user;
\q

# 3. Réimporter le schéma complet
sudo -u postgres psql -f /home/aina/Documents/MyProject/Aiolia-event/Base/schema.sql

# 4. Importer les données (logic.sql et data.sql)
sudo -u postgres psql -d aiolia_event -f /home/aina/Documents/MyProject/Aiolia-event/Base/logic.sql
sudo -u postgres psql -d aiolia_event -f /home/aina/Documents/MyProject/Aiolia-event/Base/data.sql

# 5. Si vous avez une sauvegarde de données
sudo -u postgres psql -d aiolia_event -f backup_data_XXXXXXXXX.sql
```

### Option 2 : Ajout Incrémental (Garder les Données)

**Si vous voulez GARDER vos données existantes** :

```bash
# Méthode 1 : Avec sudo
```

## 🐛 Dépannage

### Erreur : "column already exists"
**Solution** : Normal si vous faites l'option 2. Ignorez l'erreur, continuez.

### Erreur : "must be owner of table"
**Solution** : Utilisez `sudo -u postgres` ou connectez-vous en tant que postgres.

### Erreur : "relation does not exist"
**Solution** : Le schéma n'a pas été créé. Utilisez l'Option 1 (réimportation complète).

### Page Ticket Chance affiche "Erreur 500"
**Solutions** :
1. Vérifiez que les colonnes existent : voir section "Vérification" ci-dessus
2. Videz le cache : `php bin/console cache:clear`
3. Vérifiez les logs : `tail -f var/log/dev.log`
